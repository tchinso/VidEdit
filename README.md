# 📦 Discord 20MB 미디어 도구

Discord 무료 플랜의 파일당 **20MB 제한**에 맞춰 이미지와 동영상을 브라우저에서 처리하는 웹 앱입니다. 파일은 서버로 전송되지 않습니다.

## 주요 기능

- **20MB 무료 플랜 고정**: Nitro 등의 플랜 선택 없이 모든 압축 결과를 20MB 이하로 목표 처리합니다.
- **이미지 압축**: Rust/WASM으로 여러 이미지를 한 번에 압축합니다.
- **동영상 압축**: WebCodecs를 우선 사용하고, 지원하지 않는 환경에서는 Canvas + MediaRecorder 방식으로 처리합니다.
- **동영상 속도 조절**: 전체 영상 또는 지정한 시간 구간만 0.25배~4배로 바꿀 수 있습니다. 구간 시작·종료 시간은 **0.1초 단위**로 입력합니다.
- **영상 자르기**: 시작·종료 시간을 0.1초 단위로 지정해 필요한 구간만 저장합니다.
- **로컬 처리와 취소**: 처리 중인 동영상 작업을 취소할 수 있으며, 원본 파일은 브라우저 밖으로 나가지 않습니다.

속도 조절과 자르기는 결과 크기도 20MB 이하를 목표로 다시 인코딩합니다. 브라우저의 영상 코덱 지원 여부에 따라 결과 파일은 MP4 또는 WebM일 수 있습니다.

## 사용 방법

1. 원하는 도구 탭을 엽니다.
2. 파일을 놓거나 클릭해서 선택합니다.
3. 속도 조절·자르기에서는 미리보기 아래의 시간을 0.1초 단위로 설정한 뒤 실행합니다.
4. 결과 카드에서 미리보거나 다운로드합니다.

## 기술 구성

| 기능 | 기술 |
| --- | --- |
| 이미지 압축 | Rust/WASM |
| 동영상 압축 | WebCodecs, mp4box.js, mp4-muxer |
| 속도 조절·자르기 | Canvas API, Web Audio API, MediaRecorder |
| 프런트엔드 | HTML, CSS, Vanilla JavaScript |
