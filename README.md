# 🧡 Media Studio

브라우저에서 이미지와 동영상을 편집·변환·분석하는 로컬 미디어 도구입니다. 선택한 파일은 서버로 전송되지 않습니다.

## 도구

| 구분 | 기능 |
| --- | --- |
| 이미지 편집 | 20MB 이미지 압축, 형식 변환, 하단 여백 편집, 병합, 회전, 크기 조절, 흐림 효과, 레이어 합성 |
| 이미지 분석 | 주요 HEX 색상 분석, 도트화, 재압축 차이·채널·노이즈·선명도 기반 이미지 검사 |
| 동영상 | 20MB 동영상 압축, 속도 조절, 구간 자르기 |

이미지 합성은 원본과 여러 레이어를 드래그하거나 터치로 이동·확대·회전할 수 있으며, PNG로 내보낼 수 있습니다. 색상 분석 결과는 CSV와 팔레트 PNG로 저장할 수 있습니다.

## Discord 20MB 압축

이미지 압축, 동영상 압축, 영상 속도 조절 및 자르기는 Discord 무료 플랜의 파일당 **20MB 이하**를 목표로 처리합니다. 범용 편집·분석 도구는 원본 품질을 우선하므로 이 제한을 강제하지 않습니다.

## 기술 구성

| 기능 | 기술 |
| --- | --- |
| 이미지 압축 | Rust/WASM |
| 이미지 편집·분석·합성 | Canvas API, Web APIs |
| 동영상 압축 | WebCodecs, mp4box.js, mp4-muxer |
| 동영상 편집 | Canvas API, Web Audio API, MediaRecorder |
| 프런트엔드 | HTML, CSS, Vanilla JavaScript |

## 사용

정적 파일을 웹 서버로 열어 사용하세요. GitHub Pages 배포도 지원합니다.
